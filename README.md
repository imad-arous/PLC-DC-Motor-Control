# PLC-DC-Motor-Control
Industrial automation workshop focused on PLC-based control of a DC motor using Ladder Logic, Instruction List (IL), GRAFCET, and electrical wiring principles.

## Overview

This project presents the automation of a DC motor starting system using a Programmable Logic Controller (PLC). The system was developed as part of an Industrial Automation workshop at the University of Science and Technology Houari Boumediene (USTHB).

The project demonstrates the complete design process, from classical electrical control to PLC implementation using industrial programming standards.

---

## Objectives

- Design a DC motor starting circuit
- Implement automatic self-holding control
- Program the PLC using Ladder Logic
- Develop the equivalent Instruction List (IL) program
- Design the corresponding GRAFCET
- Produce the PLC wiring diagram
